# Ecommerce Marketing Skills for Claude

13 AI-powered workflow systems built for DTC and ecommerce teams. Install once, then describe what you need in plain English.

## What's inside

### UGC Campaign Management (4 skills)
- **UGC Creative Briefer** — Generate ready-to-send creator briefs with hook angles and deliverable specs
- **UGC Creator Outreach** — Find matching creators and write personalized outreach messages
- **UGC Content Reviewer** — Score submitted content and write revision notes
- **UGC Performance Tagger** — Analyze ad data and decide what to scale or kill

### SEO & Content Engine (4 skills)
- **Keyword Researcher** — Find high-intent keywords clustered by topic
- **Content Planner** — Build detailed content briefs a writer can execute
- **Content Writer** — Write SEO-optimized first drafts with quality scorecards
- **Monthly Ranking Reviewer** — Audit rankings and find quick wins

### Affiliate Program Management (5 skills)
- **Affiliate Recruiter** — Find and reach out to the right partners
- **Onboarding Kit Maker** — Create complete welcome packages
- **Content & Placement QA** — Audit affiliate sites for compliance
- **Performance Optimizer** — Design tiered commissions and motivate partners
- **Monthly Payout & Reporting** — Generate reports and calculate payouts

## Install

```
claude plugin add github:Join-Ground-AI/Ecommerce-Marketing-Skills
```

That's it. All 13 skills are now available in Claude.

## Requirements

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview) installed
- Claude Pro ($20/month) or Claude Max ($100/month) subscription

## Usage

Just describe what you need in plain English:

```
"I need a UGC brief for our new skincare serum targeting women 25-40"
```

```
"Here are our Meta ad metrics — tell me what to scale or kill"
```

```
"Do keyword research for our DTC mattress brand"
```

Claude automatically picks the right skill and runs the workflow.
